# Workstation

A dark navy constellation of glass nodes on a rolling sphere. Select a node, keep notes, and color the orb. Five independent spheres (8 / 16 / 32 / 64 / 128) remember their own titles and notes.

**Live site:** [https://mecca-research.github.io/User-Interface-Skins-/](https://mecca-research.github.io/User-Interface-Skins-/)

## Use

- Drag to rotate the sphere in place
- Double-click an orb (or click a labeled node) to unhook it into a glass window
- Double-click the title to name a node; it appears on hover
- Color lives at the bottom of the window
- Double-click the node-count control (top right) to switch sphere size

## Run locally

```bash
npm install
npm run dev
```

Open the app at the URL your environment serves (default port 8080).
