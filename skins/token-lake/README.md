# Token Lake

A receding lake of curved English script. A question sinks into the bed, a glass boat forms on the swell, and the reply fades in after the window has finished vibrating.

**Try it:** [https://mecca-research.github.io/User-Interface-Skins-/token-lake/](https://mecca-research.github.io/User-Interface-Skins-/token-lake/)

Open `index.html` or the live page. This skin is static: replies are local so the lake, the boat, and the timing can be tested without a server.
