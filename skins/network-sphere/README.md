# Network Sphere

A dark navy constellation of glass nodes on a rolling sphere.

**Try it:** [https://mecca-research.github.io/User-Interface-Skins-/network-sphere/](https://mecca-research.github.io/User-Interface-Skins-/network-sphere/)

Drag to rotate. Double-click an orb to open a glass window. Double-click a title to name it. Color sits at the bottom of the window. Double-click the count at the top right to change sphere size.

```bash
npm install
npm run dev
```
